CLI: lambda2 doctor#

The doctor command validates unified configuration without starting teleop services.

Usage#

./scripts/lambda2 doctor

Optional config path:

LAMBDA2_CONFIG=/path/to/lambda2.yaml ./scripts/lambda2 doctor

What it checks#

  • config/lambda2.yaml parse and schema version

  • Profile include paths exist

  • Role-appropriate sections present (client, robot, data, …)

  • Referenced subsystem files on disk

  • Secret file placeholders (not values)

When to run#

  • After copying *.example.yaml to local configs

  • Before first teleop on a new machine

  • After changing profile or site IP

  • In CI for documentation reproduction checks

Status#

P0 loader and doctor are implemented. Legacy teleop runtime still reads site.yaml, teleop*.yaml, and aws.json directly — doctor previews the unified schema without affecting live services.

See Configuration schema for field definitions.

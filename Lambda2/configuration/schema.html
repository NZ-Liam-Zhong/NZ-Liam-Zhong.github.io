Configuration Schema#

Unified configuration schema v1 (draft). P0 loader and doctor CLI are implemented; teleop business logic still reads legacy files.

Entry file (lambda2.yaml)#

Section

Required

Meaning

config_version

yes

Schema version, currently 1

system

yes

Name, profile, role

runtime

yes

Mode state machine and automation flags

network

yes

Inline or path: to site config

robot

yes

Agent, Tianji, grippers, chassis

client

Mac required

GELLO, workstation UI, critic haptics

video

Jetson + Mac

RTP / cameras

data

Jetson required

LeRobot recording

storage

Jetson + train

S3

pipeline

optional

Filter / train / deploy (closed loop)

includes

optional

Extra files for doctor scan

KILN learning loop#

The full software vision extends teleoperation into a closed learning pipeline:

TELEOPERATE → COLLECT → TRAIN → DEPLOY → IMPROVE TOGETHER

Site

Components

Operator

Dual GELLO station, risk network (S_\phi) for haptic guidance

Cloud

Communication relay, S3 data store, dual-network trainer (risk + policy heads)

Remote robot

Robot runtime, policy network (\pi_\theta), cameras and state

The KILN open-source release currently focuses on the teleoperation + collection path; closed-loop policy deployment is configurable but optional.

Repository modules#

Lambda2-teleoperation-gello/
├── client/     # Mac workstation, GELLO, chassis UI, SpaceMouse
├── jetson/     # Edge deploy bundle, streaming, agents, recording
└── config/     # Unified YAML schema, profiles, doctor CLI

Key design rules#

  1. Dual links: TLS control and RTP video are independent — debug them separately.

  2. Single operator lease: Cloud relay rejects a second simultaneous controller.

  3. Secrets out of Git: TELEOP_TOKEN and AWS keys live in environment or local files only.

  4. Matched site config: Mac and Jetson must share the same site.yaml content.

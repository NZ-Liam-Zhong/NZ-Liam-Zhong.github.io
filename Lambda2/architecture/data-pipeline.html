Data Collection Pipeline#

Teleoperation, video streaming, and LeRobot recording run in parallel on Jetson. Recording uses an RTP frame tap so it does not contend with Mac-side USB cameras.

End-to-end flow#

Mac workstation
  GELLO / SpaceMouse → workstation.py
       │ TLS :8443 (control)     UDP :5600/:5602 (video)
       ▼                         ▼
Cloud relay (relay-gz.lambdarobotics.ai)
       ▼                         ▼
Jetson Thor
  control_tunnel :9443 → thor_joint_agent :15666 → Tianji arms
  teleop-rtp: D405 → H.264 UDP → relay
            └── bgr_frame_tap → record_tap/{left,right}.bgr
  lerobot-record → datasets/lerobot/data/<repo_id>/
  upload_to_s3.sh → s3://<bucket>/<prefix>/<repo_id>/
       ▼
AWS S3 (training / labeling / replay)

Field

Default

Meaning

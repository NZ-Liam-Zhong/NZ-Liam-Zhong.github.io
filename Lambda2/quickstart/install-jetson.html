Install the Jetson Edge Stack#

The Jetson Thor runs arm control, video streaming, cloud tunnel, chassis forwarding, and optional LeRobot recording.

Runtime workspace#

On device, the live workspace is:

~/Desktop/lambda2_jetson_control/

Git sources live under jetson/ in the repository and are synced via deploy script.

From bare metal (first bring-up)#

A fresh Jetson Thor needs this before the deploy script can run:

  1. Flash JetPack: TODO(JetPack version + flashing method, e.g. NVIDIA SDK Manager)

  2. Create the lambda2 user with sudo: TODO(default credentials / creation steps)

  3. Install RealSense / D405 dependencies: TODO(librealsense install command), then verify cameras with rs-enumerate-devices

  4. Confirm SSH from the Mac works: ssh lambda2@<jetson-ip>

Already a running KILN device? Skip to Deploy from Mac.

Deploy from Mac#

cd Lambda2-teleoperation-gello
./jetson/deploy_to_jetson.sh lambda2

First-time setup on Jetson#

ssh lambda2@<jetson-ip>
cd ~/Desktop/lambda2_jetson_control

# Only when migrating from the legacy teleoperation/ layout — skip on fresh deployments
bash services/autostart/migrate_on_jetson.sh

export TELEOP_TOKEN='<your-token>'
./services/autostart/install_all.sh

# Enable user services after reboot (once)
sudo loginctl enable-linger lambda2

Git layout vs on-device layout#

jetson/
├── deploy_to_jetson.sh
├── d405_stream/                        # D405 capture (streaming dependency)
└── lambda2_jetson_control/             # Template synced to Jetson
    ├── services/
    │   ├── agents/thor_joint_agent.py
    │   ├── streaming/scripts/          # RTP + control tunnel
    │   └── autostart/                  # systemd + install_all.sh
    └── control/
        ├── peripherals/chassis/
        └── teleop/spacemouse/

Large runtime directories such as control/core/ and sdk/ are maintained on Jetson and are not fully tracked in Git.

Verify services#

  teleop-thor-agent teleop-rtp joystick-receiver

ss -ltn | grep -E '8099|15666|9100'

Site configuration on Jetson#

Keep config/site.yaml aligned with the Mac copy. After edits:

./config/apply_site_config.sh
./config/show_site_config.sh

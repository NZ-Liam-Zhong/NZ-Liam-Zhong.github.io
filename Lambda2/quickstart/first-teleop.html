First Teleop Checklist#

Use this checklist to confirm end-to-end operation after client and Jetson setup.

1. Environment#

  • TELEOP_TOKEN exported on Mac (matches relay control.env)

  • Mac and Jetson configs match — new configs: same lambda2.yaml + profile; legacy: identical site.yaml on both sides

  • Jetson user services are active (systemctl --user status ...)

2. Launch client#

export TELEOP_TOKEN='<your-token>'
./client/run_workstation_mac.sh

3. Connect cloud relay#

  • Top bar: select Cloud Relay

  • Click Connect Agent

  • No site channel timeout in logs

If timeout occurs: reconnect from Mac and inspect teleop-control-tunnel on Jetson.

4. Enable and verify arms#

  • Press Enable in workstation

  • Hold GELLO red S4 to unlock leader follow

  • Follower arms track master motion

  • Gripper keys respond (blue S3 / G)

5. Verify video (separate link!)#

  • Left/right video windows show live D405 streams

  • Jetson rtp.yaml dest_ip points to relay host in relay mode

  • teleop-rtp service running

Important: Arm control can work while video is broken. Always verify both links independently.

6. Chassis (optional)#

  • Chassis tab → Take over and start

  • Jetson listens on :9100 (ss -ltn | grep 9100) — direct mode needs this listener; cloud relay mode forwards through the 8443 chassis channel to it

  • VMR responds to joystick commands

7. Emergency stop#

  • Press E in workstation — arms disable immediately

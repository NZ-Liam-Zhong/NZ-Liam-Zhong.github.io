Install the Mac Client#

The Mac client provides the Gtk workstation, GELLO leader-arm follow, ESP32 input, and chassis UI.

Requirements#

  • macOS 12+

  • Homebrew Python 3.11+

  • System packages:

brew install gtk4 pygobject3 gstreamer

  • USB: GELLO Dynamixel bus, ESP32 combo board (optional SpaceMouse)

Install and launch#

cd Lambda2-teleoperation-gello

# Token must match the cloud relay TELEOP_TOKEN — never commit it
export TELEOP_TOKEN='<your-token>'

# Creates workstation/.venv-ws on first run
./client/run_workstation_mac.sh

# Debug: skip login page
./client/run_workstation_mac.sh --skip-login --token "$TELEOP_TOKEN"

Equivalent entry point:

cd client/workstation
./client/run_workstation_mac.sh

Directory layout#

client/
├── run_workstation_mac.sh       # One-click launcher
├── workstation/                 # Gtk UI (video + arms + chassis)
│   ├── client/                  # workstation.py, panels
│   ├── configs/                 # workstation.yaml, site.yaml
│   └── packaging/               # DMG build (published via Releases)
├── gello/                       # Dynamixel leader + follow runtime
├── chassis/                     # Chassis joystick protocol
└── spacemouse/                  # HID driver (shared with Jetson)

Primary configuration#

Main file: client/workstation/configs/workstation.yaml

Section

Purpose

mode: relay

Cloud relay vs direct LAN

relay.host

e.g. relay-gz.lambdarobotics.ai

thor.host

Jetson IP for chassis TCP

gello.config

Points to ../gello/configs/teleop.mac.yaml

chassis.*

Jetson listener port (default 9100)

GELLO calibration and serial mapping: client/gello/configs/teleop.mac.yaml

Prebuilt binary#

GitHub Releases ships Lambda2Teleop.dmg for operators who do not build from source.

  1. Download the latest Lambda2Teleop.dmg from Releases.

  2. Open the DMG and drag the app to /Applications.

  3. First launch: if macOS blocks it, right-click → Open, or run xattr -dr com.apple.quarantine /Applications/Lambda2Teleop.app.

  4. Log in with operator name + TELEOP_TOKEN from your site administrator.
